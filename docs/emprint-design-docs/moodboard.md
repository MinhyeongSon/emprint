# Emprint Moodboard Direction

## Product Inspirations

Emprint should emotionally sit somewhere between:

- Obsidian
- Cursor
- VSCode
- Linear
- Raycast
- old terminal environments
- archival libraries
- dark reading rooms

---

# Environmental Inspiration

Visual and emotional inspiration sources:

- dimly lit archives
- burned paper edges
- graphite textures
- old technical journals
- layered folders
- terminal windows
- git history visualizations
- engineering notebooks
- preserved manuscripts

---

# Emotional Tone

The workspace should feel:

- calm
- thoughtful
- immersive
- reflective
- enduring
- intelligent

NOT:
- hyperactive
- social-media-like
- gamified
- noisy

---

# Surface References

Preferred surface feeling:

- matte
- textured
- soft darkness
- warm graphite
- ash gray

Avoid:
- glossy UI
- excessive translucency
- bright white interfaces
- overly futuristic chrome

---

# Lighting Direction

Lighting should resemble:
- terminal glow
- ember warmth
- desk lamp illumination
- low-light workspaces

Not:
- RGB gaming aesthetics
- neon cyberpunk saturation

---

# Workspace Feeling

Opening Emprint should feel like:

> entering a preserved archive of thought, code, and creative history.

The interface should communicate:
- continuity
- ownership
- permanence
- evolution over time
