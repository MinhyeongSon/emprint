# Emprint Layout Philosophy

## Workspace Structure

The interface should feel like a workspace, not a feed.

Preferred structure:

- Sidebar
- Explorer
- Main editor/viewer
- Optional secondary panels
- Command overlays

---

# Sidebar Philosophy

The sidebar represents:
- accumulated work
- historical structure
- layered thinking

Inspired by:
- archive drawers
- library indexes
- git trees
- IDE explorers

The sidebar should remain:
- stable
- dense
- navigable by keyboard

---

# Editor Area

The editor is the emotional center of the product.

Prioritize:
- focus
- readability
- uninterrupted writing
- uninterrupted coding

Avoid:
- excessive overlays
- social UI
- noisy widgets

---

# Multi-Panel Support

The layout should eventually support:
- split editors
- preview panels
- git history
- AI assistant panels
- explorer trees

The architecture should anticipate future IDE-style layouts.

---

# Width Philosophy

Do not over-constrain the editor width.

Users should be able to:
- write long-form content
- inspect code comfortably
- manage dense workspaces

---

# Responsive Philosophy

Desktop-first design.

The primary target environment is:
- large monitors
- developer workstations
- creative workspaces

Avoid excessive mobile-first compromises.

---

# Layout Mood

The workspace should feel:
- calm
- grounded
- intentional
- archival
- immersive

Like entering a personal archive of thought.
